# WeatherLinkLiveCrestronDriver v2.0.17

Patch release correcting weather-source availability reporting.

- Mark the driver offline when both current-weather sources fail, while retaining the last available readings and displaying the refresh failure.
- Restore online status when current weather becomes available again.
- Keep fresh local readings online when only the cloud forecast refresh fails.

Driver identity, configuration fields, public commands and runtime library versions are unchanged. Update the existing instance; no reconfiguration is required.
