# WeatherLinkLiveCrestronDriver v2.0.16

Patch release correcting weather measurement units.

- Display local metric pressure in hPa by converting the WeatherLink library's mmHg readings. Convert cloud pressure to inHg when UK or Imperial units are selected.
- Convert cloud fallback wind from m/s to kph for Metric units or mph for UK units. Convert cloud rainfall from millimetres to inches for Imperial units.
- Load the embedded driver definition explicitly so the driver starts correctly with its named package assembly.
- Include the driver help PDF and third-party licence notices in the package.

The package is named `NeilColvin_WeatherStation_WeatherLinkLive_IP_V2.pkg`. Its driver identity, configuration fields and public commands are unchanged. Update the existing instance; no reconfiguration is required.

Runtime library versions are unchanged. Regression tests cover the unit conversions and display values.
