# WeatherLink Live Crestron Driver 2.0.12

Updates the driver dependencies to WeatherLinkLiveLibrary 1.0.3, SimpleWeatherClient 1.0.3 and Crestron.SimplSharp.SDK.Library 2.22.15.

Adds 40 offline NUnit driver tests, Visual Studio integration, and a separate processor test project in the existing solution. Its standalone tile appears in Configure under Utility and offers Unit Tests and Processor Lifecycle. The production driver and the test package have separate identities and UI assets.

The 40 unit tests pass on Windows and from the packaged assembly twice in one process. The additional lifecycle test requires hardware validation. Deployment credentials and local paths are excluded from source; no live credentials are needed by these fixtures.

Release assets include the production driver and processor test package. Only the production driver's existing NuGet wrapper is published; the processor package is not published to NuGet. See CHANGELOG.md and the processor project's README for details.
